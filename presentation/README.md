# Demo Day submission materials

This folder contains the presentation and fallbacks that travel with the
repository. The product source of truth remains the root [README](../README.md)
and the presenter run-of-show is [DEMO_FLOW.md](DEMO_FLOW.md).

| File | Use |
| --- | --- |
| `Smoothy-King-Demo-Day.pptx` | The editable five-slide, live-first Demo Day deck. |
| `presentation.html` | A self-contained interactive presentation reference. Open locally in a browser. |
| `demo_emergency_90s.mp4` | A 90-second emergency video cut for a network-failure fallback. |
| `demo_emergency.mp4` | The complete, optimized backup recording. |
| `DEMO_FLOW.md` | Five-minute presenter timing, live path, and Q&A guardrails. |

## How to use these materials

Lead with the deployed application—not the slides or video. Open the deployed
URL in a private window, sign in to the prepared demo account, and run the
live path in `DEMO_FLOW.md`. Keep the 90-second clip ready only if the network
or host fails. The full recording is reference material for rehearsal.

`presentation.html` was supplied as a saved interactive presentation. Its
wording is useful as a design/reference artifact, but product claims and final
Demo Day answers must match the repository documentation and the running app.
